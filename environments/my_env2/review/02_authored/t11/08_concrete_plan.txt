The plan once the world exists: real entities described, authored content inlined.
Stages 8, 9 and 10 are all held to this.

step 1 [read] read_wiki_contents — View DeepWiki documentation for a GitHub repository.
    repoName     = 'acme/event-sourcing'
    -> returns the repo's wiki DOCUMENTATION PROSE. It states what the project is for, how a subsystem works, what a concept means. It does NOT state licence, stars, maintainers or primary language, so a question about those has no obtainable answer here. (not known until the agent runs it)
step 2 [read] read_wiki_structure — List the DeepWiki documentation topics for a GitHub repository.
    repoName     = 'acme/event-sourcing'
    -> returns only the LIST OF DOCUMENTATION TOPIC TITLES. It can answer which areas the documentation covers, and nothing about repo metadata or the content of any page. (not known until the agent runs it)
step 3 [write] create_chat — Create a new chat; the acting user is always included as a member.
    member_ids   = u_alice_a — Alice Park @alice_a, u_ben_b — Ben Soto @ben_b
    -> creates something new
