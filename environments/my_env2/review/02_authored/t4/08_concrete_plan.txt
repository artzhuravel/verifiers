The plan once the world exists: real entities described, authored content inlined.
Stages 8, 9 and 10 are all held to this.

step 1 [read] ask_question — Ask an AI-grounded question about a GitHub repository.
    repoName     = 'rails/rails'
    question     = "What is this project's purpose and what is its primary programming language?"
    -> returns a free-text answer to any question about the repo — metadata (licence, primary language, maintainers) and prose questions alike. Nondeterministic wording, so only ask things with a stable, unambiguous answer. (not known until the agent runs it)
step 2 [write] reply_to — Reply to an existing message in its chat (threaded).
    message_id   = m_001 — in infra-team from Alice Morgan, unread by you: "Security flagged dependency 'belmont/cache' — can someone prepare a short repo summary (license, primary language, active maintainers/contact) and post it here by EOD?"
    text         = "I'll take this — I'll scan belmont/cache (v1.4.1) and post a short summary (license, primary language, maintainer/contact) here by EOD."
    -> creates something new
step 3 [write] reply_to — Reply to an existing message in its chat (threaded).
    message_id   = the message step 2 creates
    text         = "Starting the scan now; will update this thread with the short summary when it's ready."
    -> creates something new
step 4 [write] send_message — Send a message from the acting user to a chat.
    chat_id      = c_001 — group 'infra-team' — members: Sam Ortiz @you, Alice Morgan @alice_m, Ben Cho @ben_c, Claire Nguyen @claire_n
    text         <- must carry what step 1 returned
    -> creates something new
