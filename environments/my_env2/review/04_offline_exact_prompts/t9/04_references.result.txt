Stage 4. Each seed entity gets ONE way of being described instead of named.
The model picks only WHICH mode; the adapter derives the params from the world and
proves resolve(state, mode, params) == [that entity]. A mode that cannot be made to fit
is skipped and the next tried, so the stage is total — an entity with no working
reference raises, because v2 strips ids out and the task would be unanswerable.

  $user_0  ->  u_person0
      the entity      Person 0 @person0
      mode chosen     user_authored_text  (model proposed None; it did not fit, this is the fallback)
      params derived  {"text": "concerns widget 0 and"}
      reads as        "whoever wrote the message about concerns widget 0 and"
      predicate       the user who wrote the one message whose text contains concerns widget 0 and
      PROOF           resolve() -> ['u_person0']   unique, and it is the target

  $message_0  ->  m_001
      the entity      in room-0 from Person 0, unread by you: 'note 0 concerns widget 0 and nothing else'
      mode chosen     message_by_text  (model proposed None; it did not fit, this is the fallback)
      params derived  {"text": "concerns widget 0 and"}
      reads as        "the message about concerns widget 0 and"
      predicate       the one message whose text contains concerns widget 0 and
      PROOF           resolve() -> ['m_001']   unique, and it is the target

      PROOF           resolve() -> ['c_001']   unique, and it is the target
