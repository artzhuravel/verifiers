The plan once the world exists: real entities described, authored content inlined.
This is what every rung is held to.

step 1 [write] create_chat — Create a new chat; the acting user is always included as a member.
    member_ids   = u_person0 — Person 0 @person0
    -> creates something new
step 2 [read] read_wiki_contents — View DeepWiki documentation for a GitHub repository.
    repoName     = 'canned text for $repoName_0'
    -> returns the repo's wiki DOCUMENTATION PROSE. It states what the project is for, how a subsystem works, what a concept means. It does NOT state licence, stars, maintainers or primary language, so a question about those has no obtainable answer here. (not known until the agent runs it)
step 3 [read] read_wiki_structure — List the DeepWiki documentation topics for a GitHub repository.
    repoName     = 'canned text for $repoName_1'
    -> returns only the LIST OF DOCUMENTATION TOPIC TITLES. It can answer which areas the documentation covers, and nothing about repo metadata or the content of any page. (not known until the agent runs it)
step 4 [write] send_message — Send a message from the acting user to a chat.
    chat_id      = c_001 — group 'room-0' — members: You @you, Person 0 @person0, Extra 0 @extra0
    text         <- must carry what step 2 returned
    -> creates something new
step 5 [write] add_reaction — Add an emoji reaction from the acting user to a message.
    message_id   = the message step 4 creates
    emoji        = 'canned text for $emoji_0'
step 6 [write] send_message — Send a message from the acting user to a chat.
    chat_id      = c_002 — group 'room-1' — members: You @you, Person 0 @person0, Extra 0 @extra0, Extra 1 @extra1
    text         <- must carry what step 2 returned
    -> creates something new
step 7 [write, an aside] mark_read — Mark every message in a chat as read by the acting user.
    chat_id      = c_003 — group 'room-2' — members: You @you, Person 0 @person0, Extra 0 @extra0
