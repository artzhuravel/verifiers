step 1 [read] get_user — Look up a user by id.
    user_id      = u_cara — Cara Singh @cara
    -> returns: cara
step 2 [read] ask_question — Ask an AI-grounded question about a GitHub repository.
    repoName     = 'pandas-dev/pandas'
    question     = "What is this project's purpose?"
    -> returns a free-text answer to any question about the repo — metadata (licence, primary language, maintainers) and prose questions alike. Nondeterministic wording, so only ask things with a stable, unambiguous answer. (not known until the agent runs it)
