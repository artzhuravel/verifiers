ACTIONS THIS TASK USES
  read_wiki_contents (read) — View DeepWiki documentation for a GitHub repository.
      repoName: GitHub repo in owner/repo form
      returns: the repo's wiki DOCUMENTATION PROSE. It states what the project is for, how a subsystem works, what a concept means. It does NOT state licence, stars, maintainers or primary language, so a question about those has no obtainable answer here.
  read_wiki_structure (read) — List the DeepWiki documentation topics for a GitHub repository.
      repoName: GitHub repo in owner/repo form
      returns: only the LIST OF DOCUMENTATION TOPIC TITLES. It can answer which areas the documentation covers, and nothing about repo metadata or the content of any page.
  create_chat (write) — Create a new chat; the acting user is always included as a member.
      member_ids: user ids to include (actor added automatically)
      name: chat name; if set (or >2 members) the chat is a group, else a dm (optional)
      returns: {id, kind, name, members}
  reply_to (write) — Reply to an existing message in its chat (threaded).
      message_id: the message being replied to
      text: reply body
      returns: the created message view
  send_message (write) — Send a message from the acting user to a chat.
      chat_id: destination chat
      text: message body
      returns: the created message view
