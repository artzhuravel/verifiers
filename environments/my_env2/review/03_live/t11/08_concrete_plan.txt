The plan once the world exists: real entities described, authored content inlined.
This is what every rung is held to.

step 1 [read] read_wiki_contents — View DeepWiki documentation for a GitHub repository.
    repoName     = 'owner/acme/payment-service'
    -> returns the repo's wiki DOCUMENTATION PROSE. It states what the project is for, how a subsystem works, what a concept means. It does NOT state licence, stars, maintainers or primary language, so a question about those has no obtainable answer here. (not known until the agent runs it)
step 2 [read] read_wiki_structure — List the DeepWiki documentation topics for a GitHub repository.
    repoName     = 'owner/acme/payment-service'
    -> returns only the LIST OF DOCUMENTATION TOPIC TITLES. It can answer which areas the documentation covers, and nothing about repo metadata or the content of any page. (not known until the agent runs it)
step 3 [write] create_chat — Create a new chat; the acting user is always included as a member.
    member_ids   = u_pri — Priya Sinha @pri, u_marco — Marco Li @marco
    -> creates something new
step 4 [write] reply_to — Reply to an existing message in its chat (threaded).
    message_id   = m_001 — in backend-team from Priya Sinha, unread by you: 'Heads-up: We need to sync the payment-service runbook with the DeepWiki architecture page before Friday. Who can pull the current docs for owner/acme/payment-service?'
    text         <- must carry what step 1 returned
    -> creates something new
step 5 [write] send_message — Send a message from the acting user to a chat.
    chat_id      = c_002 — dm (unnamed dm) — members: Sam Harper @you, Owen Brooks @owen
    text         <- must carry what step 2 returned
    -> creates something new
step 6 [write] send_message — Send a message from the acting user to a chat.
    chat_id      = the chat step 3 creates
    text         = "Thanks — I pasted the docs into Priya's thread. Priya, can you lead the runbook review; Marco, can you check architecture and API and flag any issues by Thursday?"
    -> creates something new
